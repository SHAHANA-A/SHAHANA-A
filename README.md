# Vidya Student Dashboard — CANVAS 2 CODE

A responsive student dashboard concept built for the CANVAS 2 CODE front-end competition.

## Features
- Responsive green sidebar and dashboard layout
- Six pastel subject cards with progress indicators
- Search filters subjects and recent activities
- Subject details dialog
- Interactive calendar with month navigation and selectable dates
- To-do list with completion tracking and add-task form
- Notifications, profile, online-user and quick-link demo interactions
- Keyboard focus styles and reduced-motion support

## Technologies and libraries
- **HTML5** — semantic page structure
- **CSS3** — layout, responsive design, colors, and transitions
- **JavaScript (Vanilla)** — dashboard interactions
- **Lucide** — interface icons, loaded from the Lucide CDN
- **Google Fonts (DM Sans and Manrope)** — typography
- **GitHub Pages** — suggested static hosting platform

External resources actually used in the page are Lucide and Google Fonts. If the internet is unavailable, the page still works, but the icon/font appearance may fall back to defaults.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
3. No build command or package installation is required.

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown on the Pages settings screen.

## Customization
- Replace `assets/college-logo.jpg` with a cleaner transparent college logo if available.
- Update the demo profile, activities, tasks, and course links with accurate details.
- The dashboard uses illustrative demo data; it is not connected to a real college portal.

## Accessibility notes
- Semantic landmarks and labels are included.
- Interactive controls have accessible names and visible keyboard focus.
- A live region announces toast messages.
- Reduced-motion preferences are respected.
